# Laravel Blog Platform

A feature-rich blog platform built with Laravel 10, Tailwind CSS, and the TALL stack. This project includes a complete authentication system, user roles (Admin and User), post and category management, a commenting system, and a clean, responsive user interface.

## Key Features

- **Authentication:** Secure user registration and login functionality provided by Laravel Breeze.
- **User Roles:**
    - **Admin:** Has full control over the platform, including managing all posts, categories, and comments.
    - **Registered User:** Can create/manage their own posts, comment on any post, and manage their own profile.
- **Admin Panel:** A dedicated backend interface for administrators to manage site content.
    - Full CRUD (Create, Read, Update, Delete) for blog posts.
    - Full CRUD for categories.
- **Public Blog Interface:**
    - Clean, responsive blog index page to display all posts.
    - Detailed view for individual posts.
    - Users can create, edit, and delete their own posts directly from the blog interface.
- **Commenting System:** Authenticated users can post comments on blog articles and delete their own.
- **Profile Management:** Users can update their profile information and upload a custom avatar.
- **File Storage:** Handles uploads for post feature images and user avatars, including deleting old files when new ones are uploaded.


## Technology Stack

- **Backend:** PHP / Laravel 10
- **Frontend:** Tailwind CSS, Alpine.js
- **Authentication:** Laravel Breeze
- **Database:** MySQL (or your preferred choice)
- **Roles & Permissions:** `spatie/laravel-permission`
